# 🥔 Potato Leaf Disease Classifier (تصنيف أمراض أوراق البطاطا)

نظام ذكاء اصطناعي وتعلم عميق لتصنيف صور أوراق البطاطا إلى **سليمة (Healthy)** أو **مصابة (Diseased)**، مدعوم بواجهة ويب تفاعلية لاختبار الصور بشكل فوري.

---

## 📂 محتويات المستودع
* **`NN__Lab (1).ipynb`**: دفتر العمل (Jupyter Notebook) الخاص بمعالجة الصور، تدريب النموذج، وتقييم دقة التصنيف.
* **`potato-disease-classifier/`**: تطبيق الواجهة الأمامية (Frontend) المبني لتجربة النموذج ورفع الصور للتصنيف.
* **`test/`**: مجموعة عينات صور (Healthy, Early Blight, Late Blight) لاختبار أداء النموذج.

---

## 🛠️ التقنيات والأدوات المستخدمة
* **الذكاء الاصطناعي ومعالجة الصور:** Python, Jupyter Lab, Deep Learning / Computer Vision
* **تطوير الواجهة التفاعلية:** TypeScript, React, Vite (`npm run dev`)

---

## 🚀 طريقة تشغيل واجهة الويب محلياً
1. انتقلي إلى مجلد التطبيق:
   `cd potato-disease-classifier`
2. ثبّتي المكتبات المطلوبة:
   `npm install`
3. شغّلي خادم التطوير المحلي:
   `npm run dev`
